# Go Blog

**Source**: https://go.dev/blog

Release notes plus genuine design-rationale writing from the core team.
Go changes slowly enough that every release's changes are absorbable.

## Consistently worth reading

- Every release's "Go 1.N is released" post + release notes
- "Errors are values" (Rob Pike) — reframes error handling entirely
- "Go Slices: usage and internals" — the definitive slice explainer
- "Go Concurrency Patterns: Pipelines and cancellation"
- "Constants" — why untyped constants work the way they do
- The generics design posts (2021-2022) — unusually good on trade-offs
