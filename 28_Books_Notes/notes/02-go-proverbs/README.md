# Go Proverbs

**Source**: https://go-proverbs.github.io — Rob Pike's 2015 talk

Each proverb is a compressed argument. The value isn't memorizing them;
it's unpacking *why* each is claimed, and finding where it doesn't apply.

## Proverbs most worth a full note each

- "Don't communicate by sharing memory; share memory by communicating."
- "A little copying is better than a little dependency."
- "Clear is better than clever."
- "The bigger the interface, the weaker the abstraction."
- "Make the zero value useful."
- "errors are values"
